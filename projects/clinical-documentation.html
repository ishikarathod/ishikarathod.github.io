Clinical Documentation Automation

A documentation pipeline built with LLMs, NLP and speech to text that cut manual effort by 99.8%.

Detail I/R®

Context

Clinicians were spending a large share of every shift writing up what they had just done. The work was necessary, repetitive, and the worst possible use of their time. I started by gathering requirements directly from the end users rather than from a specification, because the people doing the typing knew exactly where the process broke.

What I built

A scoped data pipeline using LLMs (OpenAI) for structuring and summarisation, NLP for entity extraction, and deep learning (Whisper) for transcription. The design goal was a draft good enough that reviewing it was faster than writing from scratch, not a system that claimed to be autonomous.

Validation

Iterative testing with continuous improvement feedback loops, run with the same end users who set the requirements. Each round tightened the prompt structure and the extraction rules against real transcripts rather than synthetic ones.

Outcome

Manual documentation effort dropped by 99.8% and the model reached 94% accuracy. The more durable result was the working relationship: clinicians who had been sceptical of automation became the people specifying what it should do next.
